Theory & Background

2.1 DNA Sequencing — Brief History

1977 mein Frederick Sanger ne chain-termination method develop ki — "First Generation Sequencing". Ye method accurate thi lekin slow aur expensive. Human Genome Project (1990–2003) mein $3 billion aur 13 saal lage poore genome ko sequence karne mein. Aaj NGS se ek human genome sirf $300–600 mein 2–3 din mein sequence ho jaata hai.

2.2 NGS Kaise Kaam Karta Hai?

🧬
Step 1: Library Preparation
DNA extract → Fragment (150–300 bp) → Adapters ligate → PCR amplify
🔄
Step 2: Cluster Generation
DNA fragments flow cell pe bind → Bridge amplification → Clusters form (identical copies)
📸
Step 3: Sequencing by Synthesis
Fluorescent dNTPs → Laser imaging → Base-by-base read → FASTQ output (quality scores)
💻
Step 4: Data Analysis
QC → Alignment → Variant Calling → Annotation → Interpretation

2.3 Key Concepts

  • Read Depth / Coverage: Har genomic position kitni baar sequence hua. WES mein minimum 20–30x, ideally 100x. Zyada coverage = zyada accurate variant calling.
  • FASTQ Format: Raw sequencing output. Har read ke 4 lines: ID, Sequence, '+', Quality scores (Phred scale). Q30 = 99.9% accuracy.
  • SAM/BAM Format: Aligned reads ka format. SAM = text, BAM = binary compressed. CIGAR string alignment describe karti hai.
  • VCF Format: Variant Call Format. CHROM, POS, REF, ALT, QUAL, FILTER, INFO fields. Standard output of variant callers.
  • SNP vs Indel: SNP = single nucleotide polymorphism (substitution). Indel = insertion/deletion. Frameshift indels protein function disrupt karte hain.
  • Variant Filtration (VQSR): GATK ka Variant Quality Score Recalibration — machine learning se true variants ko false positives se distinguish karta hai.
  • Phred Quality Score: Q = -10 × log₁₀(P). Q20 = 99% accuracy; Q30 = 99.9%; Q40 = 99.99%. Standard threshold = Q30.

Bioinformatics Pipeline

🔬 Pipeline: GATK4 Best Practices (WES Variant Calling)
FASTQ (Raw Reads) → QC (FastQC) → Trimming (Trimmomatic) → Alignment (BWA-MEM2 + hg38) → Sort & Index (Samtools) → Mark Duplicates (Picard) → BQSR (GATK) → Variant Calling (HaplotypeCaller) → Genotyping (GenotypeGVCFs) → Filtering (VQSR) → Annotation (SnpEff/VEP) → Visualization (R/Python) → Clinical Report
⚠️ Important: Reference Genome
hg38 (GRCh38) use karna recommended hai — ye latest human reference genome hai. hg19 older hai lekin aaj bhi kaafi published datasets mein use hota hai. Liftover tools se hg19 → hg38 conversion possible hai. Project mein consistently ek hi version use karna zaroori hai.

Bash Pipeline Code

Niche complete automated Bash pipeline script hai jo FASTQ se annotated VCF tak ka poora workflow automate karta hai:

bash · ngs_pipeline.sh 
#!/bin/bash
# ================================================================
# NGS Variant Calling Pipeline — M.Sc Bioinformatics Project
# Author: [Your Name] | Institution: [Your University]
# Reference: GATK4 Best Practices (hg38)
# ================================================================

# ---------- CONFIGURATION ----------
SAMPLE="NA12878"
THREADS=8
REF="/data/reference/hg38.fa"
KNOWN_SITES="/data/reference/dbsnp_146.hg38.vcf.gz"
MILLS="/data/reference/Mills_and_1000G_gold_standard.indels.hg38.vcf.gz"
R1="${SAMPLE}_R1.fastq.gz"
R2="${SAMPLE}_R2.fastq.gz"
OUTDIR="./results/${SAMPLE}"

mkdir -p $OUTDIR/{qc,aligned,variants,annotated}

# ===== STEP 1: QUALITY CONTROL =====
echo "[STEP 1] Running FastQC..."
fastqc -t $THREADS -o $OUTDIR/qc $R1 $R2
multiqc $OUTDIR/qc -o $OUTDIR/qc/multiqc_report

# ===== STEP 2: TRIMMING =====
echo "[STEP 2] Trimming adapters with Trimmomatic..."
trimmomatic PE -threads $THREADS -phred33 \
  $R1 $R2 \
  $OUTDIR/qc/${SAMPLE}_R1_trimmed.fq.gz \
  $OUTDIR/qc/${SAMPLE}_R1_unpaired.fq.gz \
  $OUTDIR/qc/${SAMPLE}_R2_trimmed.fq.gz \
  $OUTDIR/qc/${SAMPLE}_R2_unpaired.fq.gz \
  ILLUMINACLIP:TruSeq3-PE.fa:2:30:10 LEADING:3 TRAILING:3 \
  SLIDINGWINDOW:4:15 MINLEN:36

# ===== STEP 3: ALIGNMENT =====
echo "[STEP 3] Aligning with BWA-MEM2..."
bwa-mem2 mem -t $THREADS \
  -R "@RG\tID:${SAMPLE}\tSM:${SAMPLE}\tPL:ILLUMINA\tLB:lib1\tPU:unit1" \
  $REF \
  $OUTDIR/qc/${SAMPLE}_R1_trimmed.fq.gz \
  $OUTDIR/qc/${SAMPLE}_R2_trimmed.fq.gz \
  | samtools sort -@ $THREADS -o $OUTDIR/aligned/${SAMPLE}_sorted.bam
samtools index $OUTDIR/aligned/${SAMPLE}_sorted.bam

# ===== STEP 4: MARK DUPLICATES =====
echo "[STEP 4] Marking duplicates with Picard..."
picard MarkDuplicates \
  I=$OUTDIR/aligned/${SAMPLE}_sorted.bam \
  O=$OUTDIR/aligned/${SAMPLE}_dedup.bam \
  M=$OUTDIR/aligned/${SAMPLE}_dup_metrics.txt \
  REMOVE_DUPLICATES=false VALIDATION_STRINGENCY=SILENT
samtools index $OUTDIR/aligned/${SAMPLE}_dedup.bam

# ===== STEP 5: BASE QUALITY SCORE RECALIBRATION (BQSR) =====
echo "[STEP 5] Running GATK BQSR..."
gatk BaseRecalibrator \
  -I $OUTDIR/aligned/${SAMPLE}_dedup.bam \
  -R $REF \
  --known-sites $KNOWN_SITES \
  --known-sites $MILLS \
  -O $OUTDIR/aligned/${SAMPLE}_recal.table

gatk ApplyBQSR \
  -I $OUTDIR/aligned/${SAMPLE}_dedup.bam \
  -R $REF \
  --bqsr-recal-file $OUTDIR/aligned/${SAMPLE}_recal.table \
  -O $OUTDIR/aligned/${SAMPLE}_BQSR.bam

# ===== STEP 6: VARIANT CALLING =====
echo "[STEP 6] Calling variants with HaplotypeCaller..."
gatk HaplotypeCaller \
  -I $OUTDIR/aligned/${SAMPLE}_BQSR.bam \
  -R $REF \
  -O $OUTDIR/variants/${SAMPLE}.g.vcf.gz \
  -ERC GVCF \
  --dbsnp $KNOWN_SITES

gatk GenotypeGVCFs \
  -R $REF \
  -V $OUTDIR/variants/${SAMPLE}.g.vcf.gz \
  -O $OUTDIR/variants/${SAMPLE}_raw.vcf.gz

# ===== STEP 7: VARIANT FILTRATION (Hard Filtering for single sample) =====
echo "[STEP 7] Filtering variants..."

# SNP Filtration
gatk SelectVariants -R $REF -V $OUTDIR/variants/${SAMPLE}_raw.vcf.gz \
  --select-type-to-include SNP -O $OUTDIR/variants/snps_raw.vcf.gz

gatk VariantFiltration -R $REF -V $OUTDIR/variants/snps_raw.vcf.gz \
  --filter-expression "QD < 2.0" --filter-name "QD2" \
  --filter-expression "FS > 60.0" --filter-name "FS60" \
  --filter-expression "MQ < 40.0" --filter-name "MQ40" \
  -O $OUTDIR/variants/snps_filtered.vcf.gz

# ===== STEP 8: ANNOTATION =====
echo "[STEP 8] Annotating variants with SnpEff..."
snpEff ann -v GRCh38.99 \
  $OUTDIR/variants/snps_filtered.vcf.gz \
  > $OUTDIR/annotated/${SAMPLE}_annotated.vcf

echo "✅ Pipeline Complete! Results in: ${OUTDIR}"

Python QC & VCF Analysis

python · vcf_analysis.py 
"""
NGS VCF Analysis & Quality Metrics — Python Script
M.Sc Bioinformatics Project
"""

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
import gzip, re
from collections import defaultdict

# ============================================================
# 1. VCF PARSER — Extract variant information
# ============================================================
def parse_vcf(vcf_path):
    """Parse VCF file and return DataFrame with variant details."""
    records = []
    opener = gzip.open if vcf_path.endswith('.gz') else open
    
    with opener(vcf_path, 'rt') as f:
        for line in f:
            if line.startswith('#'): continue
            cols = line.strip().split('\t')
            if len(cols) < 8: continue
            
            chrom, pos, vid, ref, alt, qual, filt, info = cols[:8]
            
            # Determine variant type
            if len(ref) == len(alt) == 1:
                vtype = "SNP"
            elif len(ref) > len(alt):
                vtype = "Deletion"
            elif len(ref) < len(alt):
                vtype = "Insertion"
            else:
                vtype = "MNP"
            
            # Extract DP (depth) and AF from INFO field
            dp_match = re.search(r'DP=(\d+)', info)
            af_match = re.search(r'AF=([\d.]+)', info)
            depth = int(dp_match.group(1)) if dp_match else None
            af = float(af_match.group(1)) if af_match else None
            
            records.append({
                'CHROM': chrom, 'POS': int(pos),
                'REF': ref, 'ALT': alt,
                'QUAL': float(qual) if qual != '.' else None,
                'FILTER': filt, 'TYPE': vtype,
                'DEPTH': depth, 'AF': af
            })
    
    return pd.DataFrame(records)

# ============================================================
# 2. TRANSITION/TRANSVERSION (Ti/Tv) RATIO
# ============================================================
def calculate_titv(df):
    """
    Ti/Tv ratio: Quality metric for SNP calling accuracy.
    Expected: WGS ~2.0, WES ~3.0-3.3, CpG sites ~4.0
    """
    transitions = {'A':'G', 'G':'A', 'C':'T', 'T':'C'}
    snps = df[df['TYPE'] == 'SNP'].copy()
    
    snps['is_ti'] = snps.apply(
        lambda r: transitions.get(r['REF']) == r['ALT'], axis=1
    )
    ti = snps['is_ti'].sum()
    tv = len(snps) - ti
    ratio = ti / tv if tv > 0 else 0
    
    print(f"  Transitions (Ti): {ti:,}")
    print(f"  Transversions (Tv): {tv:,}")
    print(f"  Ti/Tv Ratio: {ratio:.2f} (Expected WES: ~3.0)")
    return ratio

# ============================================================
# 3. VARIANT STATISTICS SUMMARY
# ============================================================
def variant_summary(df):
    print("\n===== VARIANT SUMMARY =====")
    print(f"Total Variants     : {len(df):,}")
    print(f"PASS Variants      : {(df['FILTER']=='PASS').sum():,}")
    print(f"SNPs               : {(df['TYPE']=='SNP').sum():,}")
    print(f"Insertions         : {(df['TYPE']=='Insertion').sum():,}")
    print(f"Deletions          : {(df['TYPE']=='Deletion').sum():,}")
    print(f"Mean Quality Score : {df['QUAL'].mean():.1f}")
    print(f"Mean Read Depth    : {df['DEPTH'].mean():.1f}x")
    print(\n"Ti/Tv Analysis:")
    calculate_titv(df)

# ============================================================
# 4. VISUALIZATION — Variant Distribution Plots
# ============================================================
def plot_variant_stats(df, output_dir="./plots"):
    plt.style.use('dark_background')
    fig, axes = plt.subplots(2, 2, figsize=(14, 10))
    fig.suptitle('NGS Variant Analysis — NA12878 WES', fontsize=14, color='white')
    
    # Plot 1: Variant Type Distribution
    type_counts = df['TYPE'].value_counts()
    axes[0,0].bar(type_counts.index, type_counts.values,
               color=['#00d4ff','#7c3aed','#10b981','#f59e0b'])
    axes[0,0].set_title('Variant Type Distribution')
    axes[0,0].set_ylabel('Count')
    
    # Plot 2: Quality Score Distribution
    axes[0,1].hist(df['QUAL'].dropna(), bins=50, color='#00d4ff', alpha=0.8)
    axes[0,1].set_title('Quality Score Distribution')
    axes[0,1].set_xlabel('QUAL Score')
    axes[0,1].axvline(x=30, color='red', linestyle='--', label='Q30 threshold')
    
    # Plot 3: Read Depth Histogram
    axes[1,0].hist(df['DEPTH'].dropna(), bins=50, color='#10b981', alpha=0.8)
    axes[1,0].set_title('Read Depth Distribution')
    axes[1,0].set_xlabel('Depth (x)')
    
    # Plot 4: Variants per Chromosome
    chrom_order = [f'chr{i}' for i in list(range(1,23))+['X','Y']]
    chrom_counts = df['CHROM'].value_counts().reindex(chrom_order, fill_value=0)
    axes[1,1].bar(range(len(chrom_counts)), chrom_counts.values, color='#f59e0b')
    axes[1,1].set_title('Variant Count per Chromosome')
    axes[1,1].set_xticks(range(len(chrom_counts)))
    axes[1,1].set_xticklabels(chrom_counts.index, rotation=90, fontsize=7)
    
    plt.tight_layout()
    plt.savefig(f"{output_dir}/variant_analysis.png", dpi=300, bbox_inches='tight')
    print("✅ Plots saved!")

# ============================================================
# MAIN
# ============================================================
if __name__ == "__main__":
    df = parse_vcf("results/NA12878/annotated/NA12878_annotated.vcf")
    variant_summary(df)
    plot_variant_stats(df)

# ================================================================
# R Script: NGS Variant Visualization
# M.Sc Bioinformatics Project | ggplot2-based analysis
# ================================================================

library(ggplot2)
library(dplyr)
library(tidyr)
library(vcfR)       # VCF reading in R
library(ggridges)   # Ridge plots
library(patchwork)  # Multi-plot layout

# ---------- 1. LOAD VCF DATA ----------
vcf <- read.vcfR("results/NA12878_annotated.vcf")
vcf_df <- as.data.frame(getFIX(vcf))
vcf_df$QUAL <- as.numeric(vcf_df$QUAL)
vcf_df$POS  <- as.numeric(vcf_df$POS)

# Add variant type column
vcf_df <- vcf_df |>
  mutate(
    VAR_TYPE = case_when(
      nchar(REF) == 1 & nchar(ALT) == 1 ~ "SNP",
      nchar(REF) > nchar(ALT)  ~ "Deletion",
      nchar(REF) < nchar(ALT)  ~ "Insertion",
      TRUE ~ "MNP"
    )
  )

# ---------- 2. PLOT 1: Variant Type Donut Chart ----------
type_summary <- vcf_df |>
  count(VAR_TYPE) |>
  mutate(pct = n / sum(n) * 100)

p1 <- ggplot(type_summary, aes(x=2, y=pct, fill=VAR_TYPE)) +
  geom_bar(stat="identity", width=1) +
  coord_polar("y", start=0) +
  xlim(0.5, 2.5) +  # Donut effect
  scale_fill_manual(values=c("#00d4ff","#7c3aed","#10b981","#f59e0b")) +
  labs(title="Variant Type Distribution", fill="Type") +
  theme_void() +
  theme(plot.title=element_text(face="bold", hjust=0.5))

# ---------- 3. PLOT 2: Coverage per Chromosome ----------
chrom_order <- paste0("chr", c(1:22, "X", "Y"))

p2 <- vcf_df |>
  filter(CHROM %in% chrom_order) |>
  mutate(CHROM = factor(CHROM, levels=chrom_order)) |>
  ggplot(aes(x=CHROM)) +
  geom_bar(fill="#00d4ff", alpha=0.8) +
  theme_minimal() +
  theme(axis.text.x=element_text(angle=90, size=7)) +
  labs(title="Variant Count per Chromosome",
       x="Chromosome", y="Variant Count")

# ---------- 4. PLOT 3: Quality Score Ridge Plot ----------
p3 <- vcf_df |>
  filter(!is.na(QUAL), QUAL > 0) |>
  ggplot(aes(x=QUAL, y=VAR_TYPE, fill=VAR_TYPE)) +
  geom_density_ridges(alpha=0.7) +
  scale_fill_manual(values=c("#00d4ff","#7c3aed","#10b981","#f59e0b")) +
  theme_minimal() +
  labs(title="Quality Score by Variant Type",
       x="QUAL Score", y="") +
  theme(legend.position="none")

# ---------- 5. COMBINE & SAVE ----------
combined_plot <- (p1 | p3) / p2 +
  plot_annotation(
    title = "NGS Variant Analysis — NA12878 WES",
    subtitle = "M.Sc Bioinformatics Project | GATK4 Pipeline",
    theme = theme(plot.title=element_text(size=16, face="bold"))
  )

       width=16, height=10, dpi=300)

cat("✅ R visualization saved to results/variant_report.pdf\n")
