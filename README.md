# NGS Variant Calling Pipeline 🧬

**Author:** Arpit Raj | M.Sc Biotechnology | SRM IST Chennai

## About
End-to-end Whole Exome Sequencing (WES) variant calling pipeline
following GATK4 Best Practices. Identifies SNPs and Indels from
raw FASTQ reads.

## Tools Used
- FastQC & Trimmomatic (Quality Control)
- BWA-MEM2 (Alignment to hg38)
- GATK4 HaplotypeCaller (Variant Calling)
- SnpEff & VEP (Annotation)
- Python, R, Bash (Analysis & Visualization)

## Results
- ~85,000 SNPs identified
- ~12,000 Indels identified
- Ti/Tv Ratio: ~3.2 (WES benchmark ✓)

## How to Run
Open the notebook in Google Colab and run cells sequentially.
